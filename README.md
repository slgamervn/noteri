# NOTERI

Sổ tay ghi chú, vẽ, mind map và học bài. Chạy offline, không cần tài khoản.

**Repo:** https://github.com/slgamervn/noteri

## Cài đặt

### Trên điện thoại / máy tính
1. Sau khi bật GitHub Pages, vào: `https://slgamervn.github.io/noteri/`
2. Trên Chrome / Safari: **Add to Home Screen**.
3. Dùng như app bình thường.

## Tính năng

- Vẽ tự do + ghi chú văn bản + **Mind map** (gõ Markdown)
- Nhập PDF, ảnh, Word (.docx), Excel
- Đa ngôn ngữ (Tiếng Việt / English)
- Nhớ trạng thái lần mở cuối
- Chia sẻ nội dung (copy JSON)
- Offline (PWA)
- Giao diện ấm, giấy, animation mượt
- Hỗ trợ đa thiết bị (điện thoại, tablet, máy tính)

## Phát triển

```bash
git clone https://github.com/slgamervn/noteri.git
cd noteri
npm install
npm run dev
```
